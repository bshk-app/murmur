# Murmator: доставка моделей и выбор монетизации

- [FEATURES.html](FEATURES.html) — интерактивная оценка 54 функций: Бесплатно / Платно / С лимитом / Позже, комментарии, экспорт и импорт решений.
- [FEATURES.md](FEATURES.md) — тот же перечень для чтения и обсуждения.
- [features.json](features.json) — данные перечня, без назначенных тарифов.
- [MODEL_DELIVERY.md](MODEL_DELIVERY.md) — сравнение bundle, сетевой загрузки, Background Assets, старых ODR/SKDownload и роли StoreKit.
- [PROVIDER_STATUS.md](PROVIDER_STATUS.md) — текущий барьер проверки модели в TranslationUIProvider.

Оценки в HTML сохраняются локально в браузере при доступном хранилище. Для переноса используй экспорт JSON; CSV подходит для дальнейшей таблицы. Эти действия не меняют тарифы или доступ к функциям в приложении.

Проверена логика фильтров, сохранения/восстановления решений, CSV и безопасного отображения комментариев. Рабочая сборка приложения и покупки не изменялись.
